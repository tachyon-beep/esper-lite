1. **Replay contract v2 (audit A7):** three comparator paths — S (stay), A (shipping FOSSILIZE), B (protocol) — and seven gates: G-CONTINUITY (B−S contribution stream only, +/0/− c, ~1e-6), G-MATCHED-CONTROL (B−A: prior PV, both branches, cost, holding_warning-cessation parity, PBRS semantics, maintenance start), G-DESIGNED-DELTA (`residual = Δ_obs − Δ_designed(x) ≈ 0`; designed delta varies legitimately with dwell/branch/horizon per the frozen formula; the RESIDUAL is invariant to phase/noise/accident), G-PBRS (whole-path telescoping), G-EVENT-ORDER (half-open intervals; no epoch pays both provisional and annuity, none pays neither), G-CROSS-SLOT (adversarial neighbor-op sequences), G-THRESHOLD-VARIANCE. Raw pre-normalization assertions; adaptive-normalizer distortion measured, never folded in.
2. **Every fixed branch moved request→boundary is discount-neutralized, both signs** (`R/γ^d`), including the −0.2 branch. **The premium is frozen as the expression `0.5 + 3.0·tanh(1.0/3.0)` evaluated in-code**, not a hand-rounded decimal (which could trip the replay's own tolerance).
3. **PENDING potential — default `Φ(PENDING) := Φ(FOSSILIZED) = 6.0`** (gpt): realizes the dwell-progress forfeiture at the REQUEST instant, matching arm A's immediate-FOSSILIZE semantics (G-MATCHED-CONTROL parity) and leaving no phase-dependent boundary cliff. Claude's alternative (`Φ(HOLDING, dwell_at_request)` frozen) recorded + rejected as default (defers the forfeiture to the schedule-timed boundary → PV varies with d → phase leak; mismatches A). Replay adjudicates.
4. **Park>fossil residual (claude, executed read):** `Φ(HOLDING, capped)=7.5 > Φ(FOSSILIZED)=6.0` — the shaping term itself pays ≈+0.31 (median commit epoch) for parking over fossilizing; A2's "possibly pro-fossil" compared the wrong pair (fossil vs pruned). Shared across arms → B−A unconfounded; ~25% haircut on the designed net. Do NOT touch Φ mid-experiment; carry in Δ_designed; named suspect in GATE-DOM interpretation.
5. **Zero-slack quote hole closed:** min_window=5 ∧ ≥5 valid measurements ∧ uncancellable had NO defined path on a missed measurement. Defined: extend to the next boundary until ≥5 valid (schedule-determined → invariant-safe). Missed-measurement replay case added; r9 per-epoch HOLDING measurement-rate read queued pre-freeze.
